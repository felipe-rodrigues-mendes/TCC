# Sequencia de Skills

## Ordem Recomendada

1. `conectasolidaria-database`
2. `conectasolidaria-backend`
3. `conectasolidaria-frontend`
4. `conectasolidaria-admin-flows`
5. `conectasolidaria-qa`

## Quando Usar Cada Skill

### `conectasolidaria-database`

Usar ao alterar `bd.sql`, tabelas, seeds, chaves estrangeiras, enums, dados iniciais ou qualquer contrato de persistencia.

### `conectasolidaria-backend`

Usar ao alterar rotas, controllers, DAOs, DTOs, sessao, autenticacao, regras de validacao e fluxo de negocio.

### `conectasolidaria-frontend`

Usar ao alterar `views/`, `assets/css/style.css`, navegacao, formularios, layout e experiencia do usuario sem quebrar o fluxo PHP server-side.

### `conectasolidaria-admin-flows`

Usar ao mexer em campanhas, recebimento de doacoes, estoque, distribuicoes e qualquer fluxo exclusivo de administrador.

### `conectasolidaria-qa`

Usar ao validar regressao, montar checklist manual e conferir consistencia entre tela, controller, DAO e banco.
